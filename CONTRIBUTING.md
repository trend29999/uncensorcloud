# Contributing

Thanks for helping make local video tools easier to use.

- Report reproducible bugs through GitHub Issues, with version, OS, GPU/driver and redacted errors.
- Suggest clearer documentation or translations with a pull request.
- For application-code changes, download the corresponding source archive from Releases, preserve its directory structure, and read the build instructions and component notices. Include a focused patch or a link to your fork in an issue; the guide repository does not contain the application source tree.
- Use synthetic, non-person clips for public reproductions and demonstrations. Share only media you have permission to distribute.
- Describe actual observations and hardware. Avoid generalizing one GPU's speed or one clip's result to all users.

Do not post credentials, desktop authorization codes, private videos or unredacted account logs. For security reports, use a private contact route offered on the official website rather than exposing a vulnerability or secret in a public issue.

Preserve AGPL-3.0, upstream copyright and individual third-party license notices. Modified builds must follow the included branding notice and must not be presented as official releases.
